# 国試 出題傾向分析

Streamlitアプリで、出題頻度と過去問Excelを使って科目・大項目別の傾向を分析します。

```sh
pip install -r requirements.txt
streamlit run app.py
```

## 科目横断の見方

選択した科目・大項目から抽出した関連語句を、分析した科目以外のすべての科目（必修を含む）の過去問と照合します。語句が問題文または選択肢に含まれる問題数・割合を科目別、出題回別に表示し、第1〜24回と第25〜34回（直近10年、中項目付与済み）を比較します。「関連軸集計」はリハ医学、一般臨床、整形外科、柔整理論（Excel上の科目名は「柔道整復学」）に絞った集計です。

この分析は抽出語の一致に基づく探索であり、問題を解くために複数科目の知識が必要かどうかを自動判定するものではありません。設問内容を確認し、出題傾向の仮説を検討するための指標として利用してください。

## 記事向けの出力

分析画面では、対象中項目の出題数・大項目内の割合・出題回数を先に示し、分母の異なる回を比較できるよう年度ごとの割合も表示します。中項目ごとの集計と、各中項目の対象期間内で最も新しい問題例（正答・関連語句つき）を記事の確認用に使えます。問題例は自動選定なので、掲載前に原資料と正答を確認してください。

全件の一覧や科目横断の詳細は「詳細データ」にまとめています。ダウンロードには記事向け要約、詳細集計、条件、解釈上の注意を含めます。出題頻度は過去問の記述値であり、将来の出題を予測するものではありません。また、科目横断の一致率は抽出語句が問題文・選択肢に現れる割合で、複数科目の知識が必要な問題かどうかを示すものではありません。
