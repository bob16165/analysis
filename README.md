# 国試 出題傾向分析

Streamlitアプリで、出題頻度と過去問Excelを使って科目・大項目別の傾向を分析します。

```sh
pip install -r requirements.txt
streamlit run app.py
```

## 科目横断の見方

選択した科目・大項目から抽出した関連語句を、分析した科目以外のすべての科目（必修を含む）の過去問と照合します。語句が問題文または選択肢に含まれる問題数・割合を科目別、出題回別に表示し、第1〜24回と第25〜34回（直近10年、中項目付与済み）を比較します。「関連軸集計」はリハ医学、一般臨床、整形外科、柔整理論（Excel上の科目名は「柔道整復学」）に絞った集計です。

この分析は抽出語の一致に基づく探索であり、問題を解くために複数科目の知識が必要かどうかを自動判定するものではありません。設問内容を確認し、出題傾向の仮説を検討するための指標として利用してください。

## 記事向けの出力

分析画面では、対象中項目の出題数・大項目内の割合・出題回数を先に示し、分母の異なる回を比較できるよう年度ごとの割合も表示します。中項目ごとの集計と、各中項目の対象期間内で最も新しい問題例（正答・関連語句つき）を記事の確認用に使えます。問題例は自動選定なので、掲載前に原資料と正答を確認してください。

全件の一覧や科目横断の詳細は「詳細データ」にまとめています。ダウンロードには記事向け要約、詳細集計、条件、解釈上の注意を含めます。出題頻度は過去問の記述値であり、将来の出題を予測するものではありません。また、科目横断の一致率は抽出語句が問題文・選択肢に現れる割合で、複数科目の知識が必要な問題かどうかを示すものではありません。

### note記事のたたき台

1. 「分析」で科目・大項目・対象回を選び、「分析する」を押します。
2. 必要に応じてMEAの紹介文、自校の模試結果と集計条件、次回の分析テーマを入力します。
3. 「記事のたたき台を作成」を押し、本文を編集してMarkdownでダウンロードします。再生成すると編集済みの本文は上書きされます。

外部サービスや生成AIを使わず、定型文と分析結果を組み合わせます。文字数は改行・記号を含めて表示し、3,000〜4,000字の範囲外なら警告します。入力や対象領域の数によっては範囲内にならないため、公開前に編集してください。未入力のMEA、模試結果、次回テーマは空欄のまま掲載せず、実情を確認して補ってください。

記事中のランキングは、出題頻度表の全期間で選ばれた上位中項目を、選択期間の過去問数で並べたものです。同順位を含むため3領域とは限りません。年度比較では大項目の問題がない回を集計不可とし、中項目別のグラフは画面に表示します。Markdownにはグラフ画像ではなく作図用の表が含まれます。

第4章には、選択期間の各中項目について、問題文と全選択肢に2問以上出現した語の上位3件を載せます。同じ問題内で繰り返されても1問と数え、同数の場合は語の文字順で3件まで選びます。画面とExcelでは各語に一致した問題IDも確認できます。語句は既存の辞書・除外語と文字列抽出を用い、空白などを取り除いて正規化するため、原文の表記と完全には一致しない場合があります。語の抽出には漏れや断片があり、誤答選択肢も含むため、正答や問題の主題を示すものではありません。2問以上に出る候補がない場合はその旨を表示します。既存の「関連語句(全回集計)」とは集計期間・対象・条件が異なります。

問題例は出題回・問題番号、模範解答番号、辞書で抽出した重要語を示します。問題文や選択肢は記事に転載しません。実際の問題、図、正答、集計条件、MEAの説明や模試結果の妥当性を原資料で確認し、掲載の際は利用条件・権利関係を確認してください。抽出語は問題の主題や正答を保証しません。

## 出題トレンド分析

「出題トレンド」では、選択した大項目または中項目について、全期間・直近5/10/15回・任意範囲の出題数と出題割合を確認できます。分母は科目全体または大項目の問題数として明示し、期間割合は出題数合計を分母合計で割って算出します。大項目の問題がない回は割合の分母に含めず、科目データ自体が未収録の回とは区別します。

前期・後期差、年度別推移、回帰傾向、変動係数は別の指標です。回帰による増加・減少の判定は、有効回数8回以上、回帰推定差が±5ポイント以上、R²が0.30以上の場合に限ります。推定差が±5ポイント未満の場合は「横ばい」、対象回数不足・未収録回・回帰の当てはまり不足は「判定保留」とします。変動係数は出題割合の年度間の相対的なばらつきで、平均出題割合0%や有効データ不足では算出しません。出題の重要度や将来予測を示す指標ではありません。

分析表には集計条件、分母、収録回数、問題IDを含め、トレンド結果を既存のExcel・Markdown形式で別途ダウンロードできます。必修科目の過去問は第29回以降のみ収録されているため、それ以前を含む期間の割合は未収録回があるものとして算出しません。
