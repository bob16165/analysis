# 国試 出題傾向分析

Streamlitアプリで、出題頻度と過去問Excelを使って科目・大項目別の傾向を分析します。

```sh
pip install -r requirements.txt
streamlit run app.py
```

## 科目横断の見方

選択した科目・大項目から抽出した関連語句を、分析した科目以外のすべての科目（必修を含む）の過去問と照合します。語句が問題文または選択肢に含まれる問題数・割合を科目別、出題回別に表示し、第1〜24回と第25〜34回（直近10年、中項目付与済み）を比較します。「関連軸集計」はリハ医学、一般臨床、整形外科、柔整理論（Excel上の科目名は「柔道整復学」）に絞った集計です。

この分析は抽出語の一致に基づく探索であり、問題を解くために複数科目の知識が必要かどうかを自動判定するものではありません。設問内容を確認し、出題傾向の仮説を検討するための指標として利用してください。

## 記事向けの出力

分析画面では、対象中項目の出題数・大項目内の割合・出題回数を先に示し、分母の異なる回を比較できるよう年度ごとの割合も表示します。中項目ごとの集計と、各中項目の対象期間内で最も新しい問題例（正答・関連語句つき）を記事の確認用に使えます。問題例は自動選定なので、掲載前に原資料と正答を確認してください。

全件の一覧や科目横断の詳細は「詳細データ」にまとめています。ダウンロードには記事向け要約、詳細集計、条件、解釈上の注意を含めます。出題頻度は過去問の記述値であり、将来の出題を予測するものではありません。また、科目横断の一致率は抽出語句が問題文・選択肢に現れる割合で、複数科目の知識が必要な問題かどうかを示すものではありません。

### note記事のたたき台

1. 「分析」で科目・大項目・対象回を選び、「分析する」を押します。
2. 必要に応じてMEAの紹介文、自校の模試結果と集計条件、次回の分析テーマを入力します。
3. 「記事のたたき台を作成」を押し、本文を編集してMarkdownでダウンロードします。再生成すると編集済みの本文は上書きされます。

外部サービスや生成AIを使わず、定型文と分析結果を組み合わせます。文字数は改行・記号を含めて表示し、3,000〜4,000字の範囲外なら警告します。入力や対象領域の数によっては範囲内にならないため、公開前に編集してください。未入力のMEA、模試結果、次回テーマは空欄のまま掲載せず、実情を確認して補ってください。

記事中のランキングは、出題頻度表の全期間で選ばれた上位中項目を、選択期間の過去問数で並べたものです。同順位を含むため3領域とは限りません。年度比較では大項目の問題がない回を集計不可とし、中項目別のグラフは画面に表示します。Markdownにはグラフ画像ではなく作図用の表が含まれます。

第4章には、選択期間の各中項目について、問題文と全選択肢に2問以上出現した語の上位3件を載せます。同じ問題内で繰り返されても1問と数え、同数の場合は語の文字順で3件まで選びます。画面とExcelでは各語に一致した問題IDも確認できます。語句は既存の辞書・除外語と文字列抽出を用い、空白などを取り除いて正規化するため、原文の表記と完全には一致しない場合があります。語の抽出には漏れや断片があり、誤答選択肢も含むため、正答や問題の主題を示すものではありません。2問以上に出る候補がない場合はその旨を表示します。既存の「関連語句(全回集計)」とは集計期間・対象・条件が異なります。

問題例は出題回・問題番号、模範解答番号、辞書で抽出した重要語を示します。問題文や選択肢は記事に転載しません。実際の問題、図、正答、集計条件、MEAの説明や模試結果の妥当性を原資料で確認し、掲載の際は利用条件・権利関係を確認してください。抽出語は問題の主題や正答を保証しません。

## 出題トレンド分析

「出題トレンド」では、選択した大項目または中項目について、全期間・直近5/10/15回・任意範囲の出題数と出題割合を確認できます。分母は科目全体または大項目の問題数として明示し、期間割合は出題数合計を分母合計で割って算出します。大項目の問題がない回は割合の分母に含めず、科目データ自体が未収録の回とは区別します。

前期・後期差、年度別推移、回帰傾向、変動係数は別の指標です。回帰による増加・減少の判定は、有効回数8回以上、回帰推定差が±5ポイント以上、R²が0.30以上の場合に限ります。推定差が±5ポイント未満の場合は「横ばい」、対象回数不足・未収録回・回帰の当てはまり不足は「判定保留」とします。変動係数は出題割合の年度間の相対的なばらつきで、平均出題割合0%や有効データ不足では算出しません。出題の重要度や将来予測を示す指標ではありません。

分析表には集計条件、分母、収録回数、問題IDを含め、トレンド結果を既存のExcel・Markdown形式で別途ダウンロードできます。必修科目の過去問は第29回以降のみ収録されているため、それ以前を含む期間の割合は未収録回があるものとして算出しません。

## 再出題・類題候補とレビュー

「再出題・類題」では、問題文・選択肢・模範解答・正答をNFKC正規化し、空白を除いた一致をA（同一問題）の候補として抽出します。異なる問題については共通の文字3-gramで候補を絞り、SequenceMatcherによる文字列類似度（初期値0.85以上）と問題文内の文字3-gram重複でB（類似問題）を提示します。高めの初期閾値で候補量を抑えていますが、候補抽出であり、類似度だけで同一問題・類題と確定しません。C（関連問題）は人が追加・判定します。候補一覧・抽出条件・変更履歴・判定履歴はExcel・Markdownでダウンロードできます。

「過去問を同期して候補を抽出」を実行すると、問題ID「第N回/科目/No.N」と内容のスナップショット、内容ハッシュ、候補、レビュー、変更履歴を`analysis_review.sqlite3`に保存します。過去問Excelのハッシュも記録し、前回同期後にファイルが変わっていれば画面で警告します。問題文・選択肢・模範解答・正答に変更がなければレビュー状態を保持し、変更があった問題に関係する判定は「再確認待ち」にします。人の判定結果は自動抽出で上書きしません。問題内容の変更前後、判定の変更前後、判定根拠を画面で確認できます。データベースはローカル利用を前提とし、Gitには含めません。

## 出題基準区分別の実績

「出題基準別実績」では、既存の大項目・中項目分類を変更せず、「記載なし」を含む項目を「旧出題基準由来」、それ以外を「現行出題基準」として、確認できた項目の出題実績を比較します。項目の母集団は出題頻度表と過去問で実際に確認できた組み合わせです。公式出題基準の全項目を網羅していないため、公式基準全体に対する網羅率は算出しません。分類できない問題は別表に残します。

出題回別の問題数と問題ID、出題実績のある項目数・割合、頻度区分、年度別の区分構成を表示し、頻度区分の境界と対象期間を変更できます。頻度区分は対象期間の問題数で数え、異なる国家試験回の数は別項目で表示します。直近期間に未収録の回がある場合、項目出題実績率は算出保留にします。表示される項目出題実績率の分母は、出題頻度表または分析対象の過去問から確認できた項目数であり、公式基準全体の網羅率ではありません。

## 既存の問題形式・出題構造レビュー

既存の「問題形式・出題構造」タブでは、過去に保存した問題形式・知識要求レベル・テーマ・科目横断のレビューを保持します。既存の分類データは新しいTaxonomyへ自動変換せず、今回追加する形式・Taxonomy分析にも混在させません。新しい知識要求分析には、次節のⅠ型・Ⅱ型・Ⅲ型だけを使用します。

「過去問を同期して分類候補を更新」を実行すると、問題ID「第N回/科目/No.N」と内容を`analysis_review.sqlite3`に保存します。問題文・選択肢・模範解答・正答、図の参照、症例情報が変わった場合、既存の値と履歴を残したまま再確認待ちにします。問題が入力データから一時的に消えて再登録された場合も、以前の分類を保持し、再確認待ちの状態を維持します。変更前後の問題文・選択肢・解答および分類履歴を画面で確認できます。

テーマ分析は人が確認したテーマ名と問題ID・根拠を使い、科目間の共通テーマ、年度推移、中項目間の関連を集計します。科目横断必須の集計は、複数科目の知識が必要だと人が確認し、関連科目と判断根拠を登録した問題だけを対象とします。テーマが複数科目で共通することと、その問題を解くために複数科目の知識が必須であることは別の指標です。既存の文字列一致による科目横断分析は変更せず、探索機能として維持します。

期間・科目別の集計では対象問題数、確定分類数、構成比の分母、問題IDと根拠を確認でき、分類・出題構造の結果をExcel・Markdownで出力できます。構造分析は全科目の人間確認済みデータを対象とします。レビューDBはローカル利用を前提とし、Gitには含めません。学生個人の成績、学校別比較、模擬試験データは扱いません。

## 形式・Taxonomy分析

追加された「形式・Taxonomy」タブでは、既存の大項目・中項目を変更せず、問題形式と知識要求を補助軸として確認・集計します。問題形式は「臨床状況・症例提示」「画像使用」「組合せ問題」「計算問題」「その他」をそれぞれ該当・非該当・判定保留で保持し、TaxonomyはⅠ型（単純想起型）・Ⅱ型（解釈型）・Ⅲ型（問題解決型）・判定保留から1つを選びます。問題形式は複数を同時に該当とできるため、形式別割合の合計は100%を超えることがあります。

Excelを分類対象へ同期しても分類処理は開始されません。「ルール候補の処理を開始」後は1回50問ずつ進め、各バッチをSQLiteへ保存します。バッチ間で中断・再開でき、エラー問題だけを再処理できます。現在のルール処理は根拠が明瞭な候補だけを提示し、TaxonomyのⅡ型・Ⅲ型境界など、ルールだけで判断できない値は保留します。Ollamaのモデル名・接続設定が未確定のため、LLM判定はまだ行いません。ルール候補は人間確認済みの集計には含めず、問題一覧で根拠を確認・修正してください。

「画像使用」はExcelの「図」欄に参照があるかで判定します。現行の過去問ファイルには画像の埋め込みはなく、図の参照情報のみです。アプリは画像ファイルを抽出・表示・視覚認識しません。参照がない場合でも、画像内容をAIが確認したとは扱いません。

問題形式の割合は、各形式について人間確認済みの「該当」「非該当」の合計を分母にし、保留・未確認数と対象問題数を別に表示します。Taxonomyの割合は人間確認済みのⅠ〜Ⅲ型を分母とし、判定保留・未確認数を別表示します。全体・科目・年度・既存大項目・既存中項目別の件数と割合を確認でき、新分類の結果は専用のExcel・Markdownとして出力します。分類値、入力ハッシュ、判定根拠、確認状態、変更履歴は既存レビューDB内の独立テーブルに保存し、既存レビュー値を上書きしません。

### 出題テーマの変化・表記統合

同じ中項目内で問われるテーマの変化を、「問題形式・出題構造」タブの期間別分析で確認できます。テーマ出現頻度に使うのは「人間確認済み」「修正済み」のテーマだけです。テーマなしも含めて中項目・出題回の全問題をレビューした回だけを年度比較に使い、未確認の回は0件ではなく欠損として扱います。中項目が「記載なし」または未設定の問題はテーマ変化の母集団に含めず、問題一覧に分けて表示します。

直近期間は指定範囲の最新回から最大10回分、過去期間はその前の回です。年度別の出題割合はテーマが付与された問題数÷その中項目の問題数、期間比較の出題回割合はテーマが1問以上付与された回数÷完全レビュー済み回数です。増減判定は、過去・直近それぞれに完全レビュー済み回が3回以上ある場合に限り、出題回割合の差が+10ポイント以上なら増加、-10ポイント以下なら減少とします。新出・減少の候補も同じレビュー回数を満たすときだけ表示します。これは確認済みデータ内の記述的な比較であり、未レビュー回を含む出題傾向の結論や将来予測ではありません。

「未確認の語句候補」には既存の頻出語抽出を再利用し、中項目ごとの上位10語を表示します。問題文と全選択肢を対象にするため、誤答選択肢由来の語句や主題でない語句も含み得ます。候補は自動でテーマ分類に取り込まず、問題IDから問題ごとのレビューを開き、根拠とともに人が確定してください。

全角・半角や空白の違いはNFKC・空白除去で同一表記として扱います。同義語・別表記は確認済みテーマを統合先として、区分・表記・判断根拠を人が登録します。統合ルールの追加・変更・解除履歴はSQLiteレビューDBに保存され、確認済みテーマの共通性・年度比較に適用されます。ルールの登録はテーマ分類そのものを変更せず、語句候補も自動確定しません。分析結果には対象期間、集計条件、問題IDを含め、他の分類・出題構造分析と同じExcel・Markdown出力から確認できます。
